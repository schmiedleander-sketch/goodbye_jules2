# MatrixRain

**Category**: Fun Apps
**Description**: Animated falling green digital code rain terminal screensaver.
**Target Platform**: Windows 11 x64 (Compatible with Windows 10/11 64-bit)
**Dependencies**: 100% Self-contained static binary (zero external DLL or runtime dependencies required).

## Files in Package
- `MatrixRain.exe`: Standalone 64-bit Windows executable.
- `MatrixRainInstaller.msi`: Standard Windows Installer MSI package.
- `MatrixRain.c`: C source code.
- `MatrixRain.wxs`: WiX source configuration for the MSI.

## How to Run the .exe
Open Command Prompt or PowerShell in this directory:
```cmd
MatrixRain.exe
```

## How to Install via .msi
Run the installer directly or via msiexec:
```cmd
msiexec /i MatrixRainInstaller.msi /quiet /qn
```
